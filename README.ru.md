# ExHentai Gallery Downloader

> ⚠️ **Эта программа написана ИИ.**
>
> Этот инструмент создан исключительно для загрузки оригинальных архивов ExHentai на локальный компьютер для личного просмотра и архивирования автором. **Перед массовой загрузкой убедитесь, что у вас достаточно GP (Gallery Points)** — скрипт загружает только оригинальный архив и не загружает архивы других разрешений. Спасибо!

Автоматический загрузчик архивов галерей ExHentai / e-hentai с интерфейсами CLI и GUI.

[English](README.md) | [简体中文](README.zh-cn.md) | [繁體中文](README.zh-tw.md) | [日本語](README.jp.md)

## Известные проблемы

- **Отображение CJK-символов (китайский/японский/корейский) может иметь проблемы** — некоторые символы могут отображаться с разным размером или толщиной, что влияет на эстетику. Это ограничение текущей обработки шрифтов в GUI.

## Возможности

- **Перехват браузера**：подключение к существующей сессии Chrome через протокол удалённой отладки; пользователь вручную проходит CloudFlare, затем автоматизация берёт на себя
- **Возобновление загрузок**：HTTP Range запросы для восстановления прерванных загрузок
- **Автоматический retry**：3 попытки с экспоненциальной задержкой при сбоях
- **Дедупликация локальной библиотеки**：SQLite-индексированные локальные каталоги манги, автопропуск уже загруженных галерей
- **Сохранение очереди**：прогресс сохраняется при прерывании и восстанавливается при перезапуске
- **Лог ошибок**：запись неудачных URL с причинами, повтор одной кнопкой
- **Метаданные галерей**：сохранение названия, автора, тегов, категории в SQLite
- **Проверка целостности ZIP**：опциональная CRC-проверка после загрузки
- **Автоматическая распаковка**：опциональная распаковка ZIP в подкаталог с названием галереи
- **Каталог распаковки**：выбор каталога для распаковки (по умолчанию — каталог загрузок)
- **Удаление ZIP после распаковки**：опциональное удаление ZIP-файла после успешной распаковки
- **Скорость/ETA загрузки**：отображение скорости и оставшегося времени в реальном времени
- **Уведомления на рабочем столе**：уведомление о завершении задач
- **Многоязычность**：English, 简体中文, 繁體中文, 日本語, Русский
- **GUI**：тёмная тема на базе CustomTkinter

## Использование

### GUI-режим (рекомендуется)

```bash
python run.py
# или
python -m src.main
# или
python run.py --gui
```

1. На вкладке **Настройки** настройте:
   - **Каталог загрузок**：куда сохраняются ZIP-архивы
   - **Каталог распаковки**：куда распаковываются архивы (оставьте пустым = каталог загрузок; каждая галерея распаковывается в подкаталог с названием галереи)
   - **Пути библиотеки**：добавьте существующие каталоги манги (для дедупликации), нажмите пересканировать
   - **Браузер Chrome**：укажите путь к Chrome и каталог пользовательских данных
   - **Язык**：выберите язык интерфейса
   - **Параметры**：включите проверку целостности ZIP, авт распаковку, удаление ZIP после распаковки, уведомления
2. Нажмите **Запустить браузер**, вручную войдите в e-hentai в открывшемся Chrome
3. Нажмите **Подключить браузер**
4. На вкладке **Главная** вставьте URL галерей (по одному на строку), нажмите **Добавить URL**
5. Нажмите **Начать загрузку**

### CLI-режим

```bash
python run.py --cli
# с параметрами:
python run.py --cli --language ru --download-dir ./downloads --extract --extract-dir ./распаковка --delete-after-extract
```

Параметры CLI：

| Параметр | Описание |
|----------|----------|
| `-l, --language` | Язык интерфейса: `en`, `zh_cn`, `zh_tw`, `ja`, `ru` |
| `-d, --download-dir` | Каталог загрузок |
| `--extract` | Автоматическая распаковка ZIP после загрузки |
| `--extract-dir` | Каталог распаковки (по умолчанию: каталог загрузок) |
| `--delete-after-extract` | Удалить ZIP после распаковки |
| `--no-notify` | Отключить уведомления на рабочем столе |
| `--no-integrity` | Пропустить проверку целостности ZIP |

## Рабочий процесс

```
Ввод URL галереи -> Навигация по странице -> Извлечение названия -> Проверка дубликатов
    -> Нажать Archive Download -> Получить ссылку загрузки -> Возобновление загрузки -> Готово
    -> [Опционально: Проверка целостности, Авто распаковка, Удаление ZIP, Сохранение метаданных]
```

## Примечания

- Chrome должен быть запущен с параметром `--remote-debugging-port=9222` (GUI может запустить его)
- Вручную войдите в e-hentai.org и пройдите проверку CloudFlare при первом использовании
- Загруженные архивы в формате ZIP, имя файла — название галереи
- При включённой авт распаковке архивы распаковываются в `каталог_распаковки/название_галереи/`

## Логика дедупликации
- **В одной папке**: Изображения в одной подпапке НИКОГДА не считаются дубликатами друг друга, даже если их хеши совпадают.
- **Между папками**: Только при сравнении с другими папками сохраняется новейшая копия, а старые копии изображений удаляются.
- **Перекрытие папок**: Если процент совпадающих изображений между двумя папками превышает заданный порог (по умолчанию 50%), удаляется папка с самой старой датой изменения.
- **Удаление рекламных изображений**: Сравниваются только последние 6 изображений (отсортированные по имени) в каждой папке. Если перекрытие превышает порог (по умолчанию 50%), удаляется самая старая папка.
- **Настройка порога**: Добавлена настройка, позволяющая пользователю самостоятельно выбрать процент перекрытия.
