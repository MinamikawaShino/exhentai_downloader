# ExHentai Gallery Downloader

> ⚠️ **このプログラムはAIによって作成されています。**
>
> このツールは、作者がExHentaiのオリジナルアーカイブをローカルにダウンロードして鑑賞する目的でのみ作成しました。**一括ダウンロード前にGP（ギャラリーポイント）が十分にあるかご確認ください** — スクリプトはオリジナルアーカイブのみをダウンロードし、他の解像度のアーカイブはダウンロードしません。よろしくお願いします！

ExHentai / e-hentai ギャラリーアーカイブ自動ダウンローダー。CLIとGUIの両モードに対応。

[English](README.md) | [简体中文](README.zh-cn.md) | [繁體中文](README.zh-tw.md) | [Русский](README.ru.md)

## 既知の問題

- **CJK（中国語・日本語・韓国語）文字の表示に問題が生じる場合があります** — 一部の文字のサイズや太さが均一でなく、美観に影響する可能性があります。これは現在のGUIフォント処理の制限です。

## 機能

- **ブラウザハイジャック**：Chromeリモートデバッグプロトコルで既存のブラウザセッションに接続し、CloudFlareを手動で処理した後、自動化が引き継ぎます
- **レジュームサポート**：HTTP Rangeリクエストによる中断ダウンロードの再開
- **自動リトライ**：失敗時3回まで指数バックオフでリトライ
- **ローカルライブラリ重複排除**：SQLiteでインデックスされたローカル漫画ディレクトリ、既ダウンロードのギャラリーを自動スキップ
- **キューデータ永続化**：中断時に進捗を保存、再起動後に復元可能
- **失敗ログ**：失敗URLと理由を記録、ワンクリックでリトライ
- **ギャラリーメタデータ**：タイトル、アーティスト、タグ、カテゴリをSQLiteに保存
- **ZIP整合性チェック**：ダウンロード後のCRC検証（オプション）
- **自動解凍**：ダウンロード後、ギャラリータイトル名のサブディレクトリに自動解凍（オプション）
- **カスタム解凍ディレクトリ**：解凍先ディレクトリを選択可能（空欄の場合はダウンロードディレクトリと同じ）
- **解凍後ZIP削除**：解凍成功後にZIPを削除（オプション）
- **ダウンロード速度/ETA**：リアルタイム速度と残り時間表示
- **デスクトップ通知**：タスク完了時に通知
- **多言語**：English, 简体中文, 繁體中文, 日本語, Русский
- **GUI**：CustomTkinterベースのダークテーマデスクトップアプリケーション

## 使い方

### GUIモード（推奨）

```bash
python run.py
# または
python -m src.main
# または
python run.py --gui
```

1. **設定**タブで以下を構成：
   - **ダウンロードディレクトリ**：ZIPアーカイブの保存先
   - **展開ディレクトリ**：アーカイブの展開先（空欄の場合はダウンロードディレクトリと同じ。各ギャラリーはタイトル名のサブフォルダに展開されます）
   - **ライブラリパス**：既存の漫画ディレクトリを追加（重複排除用）、再スキャンをクリック
   - **Chrome ブラウザ**：Chromeパスとユーザーデータディレクトリを設定
   - **言語**：UI言語を選択
   - **オプション**：ZIP整合性チェック、自動解凍、ZIP削除、通知の切り替え
2. **ブラウザを起動**をクリックし、開いたChromeでe-hentaiにログイン
3. **ブラウザに接続**をクリック
4. **ホーム**タブでギャラリーURLを貼り付け（1行に1つ）、**URLを追加**をクリック
5. **ダウンロード開始**をクリック

### CLIモード

```bash
python run.py --cli
# オプション付き：
python run.py --cli --language ja --download-dir ./downloads --extract --extract-dir ./展開先 --delete-after-extract
```

CLIオプション：

| オプション | 説明 |
|-----------|------|
| `-l, --language` | UI言語: `en`, `zh_cn`, `zh_tw`, `ja`, `ru` |
| `-d, --download-dir` | ダウンロードディレクトリ |
| `--extract` | ダウンロード後自動解凍 |
| `--extract-dir` | 解凍先ディレクトリ（デフォルト：ダウンロードディレクトリと同じ） |
| `--delete-after-extract` | 解凍後ZIPを削除 |
| `--no-notify` | デスクトップ通知を無効化 |
| `--no-integrity` | ZIP整合性チェックをスキップ |

## ワークフロー

```
ギャラリーURL入力 -> ページ遷移 -> タイトル取得 -> 重複チェック
    -> Archive Download クリック -> ダウンロードリンク取得 -> レジュームダウンロード -> 完了
    -> [オプション：整合性チェック、自動解凍、ZIP削除、メタデータ保存]
```

## 注意事項

- Chromeは`--remote-debugging-port=9222`パラメータで起動する必要があります（GUIから起動可能）
- 初回使用時にChromeでe-hentai.orgにログインし、CloudFlare認証を通過する必要があります
- ダウンロードされたアーカイブはZIP形式、ファイル名はギャラリータイトル
- 自動解凍を有効にすると、`解凍先/ギャラリータイトル/`サブディレクトリに展開されます

## 重複排除ロジック
- **同一フォルダ内の無視**: 同じサブフォルダ内の画像は、ハッシュが同じであっても削除されません。
- **別フォルダ間の比較**: 他のフォルダと交差比較した場合にのみ、最新のものを保持し、古い画像のコピーを削除します。
- **フォルダ重複排除**: 2つのフォルダ間で同一画像の割合が設定されたしきい値（デフォルト50%）を超えた場合、更新日時が最も古いフォルダが削除されます。
- **広告画像の削除**: 各フォルダの最後の6枚の画像（名前順）のみを比較し、重複率がしきい値（デフォルト50%）を超えた場合、更新日時が最も古いフォルダを削除します。
- **しきい値のカスタマイズ**: この重複率の割合をユーザー自身で設定できるオプションを追加しました。
